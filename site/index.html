What TermOS is

A keyboard-first phone shell. Everything is a command you can pipe, alias, or schedule — with sudo and screen-off lock like a real multi-user box.

Launcher, not an OS

TermOS is your HOME app. Android still runs underneath; you get a green-on-black prompt, themes, and vim-style keys when you want them.

Safe by default

Your TermOS password gates sudo. AI suggests steps — it does not run them silently. Keys and history redact secrets; only browse and ai use the network.

Scriptable

Pipes, aliases, .tsh scripts, at / every jobs. Power users get a pocket Linux workflow; linux hands off to Termux when you need bash.

Type instead of tap

Common tasks map to short commands. TAB completes; history remembers. Built-in keyboard with Amharic layer ships in 0.8.

Try it on your phone

  1. Clone the repo and run ./build.sh for a debug APK.
  2. ./install.sh — or adb install the artifact under app/build/outputs/apk/debug/.
  3. Set TermOS as default launcher (Home → TermOS → Always).
  4. Create your password, optional sudo ai key …, then help or guide start.

Requires Android with launcher permissions. For timers and auto-lock, allow unrestricted battery when prompted (perms).
